# PASCO 力板垂直跳躍自動化分析系統 (PASCO Jump Auto-Analyzer)

本系統是一套專為運動科學與臨床生物力學設計的自動化分析工具，旨在將 PASCO 力板產生的專有格式 `.cap` 檔案批次轉換為 CSV 力量數據，並進行高精度的質心運動學積分與臨床進階指標計算，最終自動導出符合實驗室金標準的雙工作表（Details + CMJ / SJ）Excel 臨床診斷報告與高質感物理圖表。

---

## 📂 專案目錄結構

本系統採用「**專案子資料夾分類**」與「**單受試者大混合儲存**」之設計，輸入與輸出層級保持高度對稱，所有產出皆一目了然：

```text
PASCO_Analysis/

│   ├── cmj/                      # CMJ 動作輸出目錄
│   │   └── 2026跆拳/             # 自動繼承輸入端的專案名稱
│   │       └── 001/              # 每個 .cap 檔案專屬的獨立資料夾
│   │           ├── 001.cap       # [防重複轉換機制] 轉換完成後自動移入此處的原始檔案
│   │           ├── 001.csv       # [階段一] 轉換出的原始力量 CSV (雙力板合併)
│   │           ├── 001-1.xlsx    # [階段二] Run 1 雙 Sheet 臨床報告 (Details + CMJ)
│   │           └── 001-1_comparison.png # [階段二] Run 1 物理診斷圖
│   │
│   └── sj/                       # SJ 動作輸出目錄
│       └── SJ 原始/              # 自動繼承輸入端的專案名稱
│           └── 001/              # 每個 .cap 檔案專屬的獨立資料夾
│               ├── 001.cap       # [防重複轉換機制] 轉換完成後自動移入此處的原始檔案
│               ├── 001.csv       # [階段一] 轉換出的原始力量 CSV (雙力板合併)
│               ├── 001-1.xlsx    # [階段二] Run 1 雙 Sheet 臨床報告 (Details + SJ)
```

## 🚀 兩階段操作流程說明

本系統之執行分為兩階段，流程設計簡單且具高度防呆性。請開啟終端機（Terminal）並確保處於專案根目錄下：

### 階段一：解析與歸檔原始數據 (.cap ➡️ CSV，附防重複移動機制)

將您要分析的力板原始檔案放入對應動作專案目錄中，例如將 `.cap` 檔案置於 `inputs/cmj/專案名稱/` 或 `inputs/sj/專案名稱/` 下。

執行以下指令進行批次轉換：
```bash
python convert_cap_to_csv.py
```
*   **運作邏輯**：程式將會自動巡覽 `inputs/cmj/` 與 `inputs/sj/` 底下的所有專案資料夾。
*   **防重複機制**：每個 `.cap` 檔案轉換完成後，程式會自動將該 `.cap` 原始檔案**移動 (Move)** 到對應的 `outputs/{動作}/{專案名稱}/{受試者ID}/` 資料夾中。
*   **效益**：這能確保 `inputs/` 資料夾始終保持清爽，下次執行 `convert_cap_to_csv.py` 時，程式只會處理「新增」的力板數據，不會對已處理的舊資料重複轉換，大幅提升批次處理效率。

---

### 階段二：臨床肌力指標分析 (CSV ➡️ 雙 Sheet Excel & 診斷圖)

此階段將對已轉換的 CSV 進行低通濾波、質心運動積分與臨床指標計算。

#### A. 反向動作蹲跳 (CMJ) 分析
執行以下指令：
```bash
python analyze_cmj.py
```
*   **說明**：程式預設會生成診斷對比圖。若不需要生成圖片，可帶入 `--no-plot` 參數（例如：`python analyze_cmj.py --no-plot`）。
*   **Details 工作表**：包含 11 個特徵事件（動作開始、最大失重、重心最低、離地瞬間等）的精確時間戳、力量值、二次積分位移、速度與功率值。
*   **CMJ 工作表**：包含衝量、反應力指數 RSI、向心/離心做功量與功率峰值、下蹲/制動/推蹬發力率、以及標準化後的下肢勁度與百分比時間戳等 20 項肌力特徵。

#### B. 靜態蹲跳 (SJ) 分析
執行以下指令：
```bash
python analyze_sj.py
```
*   **說明**：程式預設會生成診斷對比圖。若不需要生成圖片，可帶入 `--no-plot` 參數（例如：`python analyze_sj.py --no-plot`）。
*   **Details 工作表**：包含 5 個特徵事件（動作開始、最大推蹬力、離地瞬間、著地瞬間、最大向心功率）。
    *   **SJ 動作開始 (SoM) 定位**：採用專門的「推蹬峰值逆向尋找法」，能自動適應完全無下蹲或受試者存在微小下蹲（偷蹲）的數據，誤差控制在 3 幀之內。
*   **SJ 工作表**：包含受試者基本資料與 7 項下肢推蹬動態肌力特徵（包含衝量、總動作時間、跳躍高度、推蹬力峰值、推蹬發力率、反應力指數、向心功率峰值、向心做功量等）。

## 🛠️ 演算法引數與參數微調

為了應對不同噪聲等級的資料，分析主程式提供了靈活的參數微調開關。您可以在執行時於終端機直接傳入參數，例如：

```bash
# 修改 Butterworth 濾波切斷頻率為 25.0 Hz，並將 SoM 門檻調低至體重的 2.0%
python analyze_sj.py --cutoff 25.0 --som-pct 0.02
```

### 可用參數一覽表：

| 參數 | 預設值 | 說明 |
| :--- | :---: | :--- |
| `--no-plot` | 否 | 若帶入此參數，則在分析後不生成診斷繪圖 (預設會生成) |
| `--force` | 否 | 是否強制重新計算並覆寫已存在的 Excel 報告 (預設跳過已存在報告) |
| `--fs` | `1000` | 力板數據的取樣頻率 (Hz) |
| `--cutoff` | `20.0` | Butterworth 低通濾波切斷頻率 (Hz) |
| `--som-pct` | `0.025` | 動作開始 (SoM) 時，力量偏離靜態體重的百分比 (2.5%) |
| `--takeoff-n` | `10.0` | 離地瞬間 (Takeoff) 的精確力量閾值 (N) |
| `--landing-n` | `30.0` | 著地瞬間 (Landing) 的精確力量閾值 (N) |
| `--landing-window`| `150` | 著地瞬間防餘震干擾之安全屏蔽窗口 (ms) |

    *   在 `CMJ` / `SJ` 工作表中以「原始」行與「%標準化」行，完整標明了所有進階指標的**詳細物理計算公式、標準化方法**，以及在實驗室控制組乾淨樣本上的**批量信效度誤差統計**。

# 🎬 運動影片關鍵幀標註工具 (Video Keyframe Annotation Tool)

這是一個專為運動力學與動作分析設計的輕量化本機網頁影片標註工具。它能協助實驗室成員或同學快速標記影片中的關鍵動作幀（如棒球投打動作的預備、轉體、擊球等），並匯出標準的 JSON 標註結果。

---

## ✨ 核心特色

1. **資料夾批次載入**：直接在網頁輸入相對路徑（如 `videos`）或本機絕對路徑，一次載入該資料夾內的所有支援影片（`.mp4`, `.mov`, `.avi` 等），免去單一上傳的繁瑣步驟。
2. **時間軸分段標籤**：
   * 採用運動科學標註邏輯，標記第 25 幀為「預備」後，`0-25 幀` 的區間都會自動繪製為預備區間並在時間軸上直觀顯示。
   * 時間軸會直接呈現對應的標籤文字與自訂顏色。
3. **極速鍵盤工作流**：
   * **快捷鍵標記**：每個標籤可綁定鍵盤快捷鍵（如 1, 2, 3, Q, W, E），看影片時按下鍵盤即可快速打上當前時間點的關鍵幀。
   * **逐幀步進 (Frame-by-Frame)**：使用鍵盤的 **「左/右」方向鍵** 可以精準倒退/前進一幀（自動讀取影片的 FPS），完美對齊動作關鍵瞬間。
   * **快速播放控制**：支援 **「空白鍵 (Space)」** 暫停/播放影片，以及切換慢動作播放速度（`0.25x`, `0.5x` 等）。
   * **一鍵儲存並下一部**：完成標註後按下 **「Enter」鍵**，系統會自動儲存標註資料並跳轉至清單中的下一部影片。
4. **自訂標籤範本**：內建範本管理視窗，可自由新增/刪除不同的動作分析範本（例如：棒球、排球、跑步），並設定標籤的快捷鍵與顏色，設定會自動保存在 `templates.json`。
5. **進度狀態追蹤**：播放清單會自動偵測哪些影片已經完成標註並存檔，顯示 **綠色打勾標章 (✔️)**，方便管理標註進度。

## 🚀 快速啟動方法 (Windows)

1. 確保你的電腦已安裝 **Python 3.10+**。
2. 進入本資料夾下，直接點擊並執行 **`run.bat`** 檔案。
3. 腳本會自動檢查並安裝相依套件 (`fastapi`, `uvicorn`, `opencv-python`)，並在瀏覽器自動開啟以下網址：
   👉 **[http://localhost:8000](http://localhost:8000)**

*(提示：若網頁伺服器運作中，請勿關閉彈出的黑底命令提示字元視窗。)*

---

## 🛠 手動啟動與開發

若是手動指令或在 VS Code 終端機中開啟：

```bash
# 1. 進入此工具資料夾
cd Video_Annotation_System

# 2. 安裝套件
pip install -r requirements.txt

# 3. 啟動 FastAPI 服務器
uvicorn main:app --reload
```
然後在瀏覽器開啟 [http://localhost:8000](http://localhost:8000)。

## 📂 資料儲存格式

標註完成後點擊儲存（或按 `Enter` 鍵），系統會在影片所在的同一個資料夾下自動儲存成同名 JSON 標註檔（例如：`baseball_01_labels.json`）：

```json
{
  "video_filename": "baseball_01.MP4",
  "fps": 30.0,
  "annotations": [
    {
      "tag": "預備",
      "timestamp_sec": 1.134,
      "frame_index": 34,
      "shortcut": "1"
    },
    {
      "tag": "轉體",
      "timestamp_sec": 1.833,
      "frame_index": 55,
      "shortcut": "2"
    },
    {
      "tag": "揮棒",
      "timestamp_sec": 2.167,
      "frame_index": 65,
      "shortcut": "3"
    }
  ]
}
```
